# bridgit (RDS-NG) Nextcloud integration

[bridgit (RDS-NG)](https://github.com/Sciebo-RDS/rds-ng) integration for Nextcloud 33 and above. Note that this application is only used to integrate a bridgit deployment into Nextcloud; you will need to deploy bridgit as well.

## Building the application

Before the application can be used, it must be built by running `make` inside its directory. This requires _PHP 8.2+_ and _Composer_ to be present on the system where you're building the application.
